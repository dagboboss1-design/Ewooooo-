# Phase 4 Chart Notes

- Added a responsive HTML canvas candlestick renderer with OHLC wicks and bodies, price scale, time labels, and bullish/bearish colors.
- Added instrument selection and M5, M15, M30, H1, H4 timeframe controls.
- Chart fetches up to 180 actual candles from /api/market/candles and displays provider errors instead of sample data.
- Resizes redraw the most recently received candle set.
- Candle rendering is visual only; no automatic strategy signals are generated by this change.
- Provider symbol entitlement and rate limits still apply. DXY remains unavailable until a dedicated index provider is configured.
- LIVE_TRADING remains false.
